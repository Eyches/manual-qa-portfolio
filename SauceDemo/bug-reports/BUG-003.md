# BUG-003: Sorting dropdown does not open when clicking the arrow

## Environment
- Application: SauceDemo (https://www.saucedemo.com/)
- Browser: Safari
- OS: macOS

## Preconditions
- The user is logged in.
- The Products page is open.

## Steps to Reproduce
1. Locate the sorting dropdown.
2. Click the downward arrow on the right side of the dropdown.

## Expected Result
The sorting dropdown menu opens when clicking the arrow.

## Actual Result
The sorting dropdown menu does not open when clicking the arrow.
The dropdown remains functional when clicking other areas.

## Severity
Low

## Priority
Low

## Technical Investigation
The sorting dropdown uses a nearly transparent HTML `<select>` element.

The visible dropdown arrow is rendered using the CSS `::after` pseudo-element.

During investigation with Safari Web Inspector, adding the following CSS property to the `::after` pseudo-element:

```css
pointer-events: none;
```

allowed the dropdown menu to open when clicking the arrow.

The cursor behavior remained unchanged.

This suggests that the pseudo-element may be intercepting pointer events.

## Status
Documented — Pending Review

## Notes
This issue was identified during independent exploratory testing
of the public SauceDemo application.

The suggested CSS change was tested locally using browser DevTools.
It has not been applied to the application's source code.
